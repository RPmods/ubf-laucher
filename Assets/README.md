# Launcher assets

Place these files in this folder before publishing:

- `background.mp4`: looping launcher background.
- `logo.png`: centered startup splash image with fade-in and fade-out; transparent PNG recommended.
- `menu_sd_laucher_badays.mp3`: first menu soundtrack.
- `menu_sd_laucher_goodays.mp3`: alternate menu soundtrack.

The splash is a separate frameless window. Music begins with the logo, alternates between the tracks, and fades over each track's final four seconds. Missing media files are logged and do not prevent the launcher from opening.
